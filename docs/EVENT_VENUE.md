## 通信が不安定なとき

1. 注文の応答を受け取れない場合は、店舗側へ伝える前のアプリ内受付が済んでいる可能性があります。「未送信」と断定しません。
2. 結果不明の商品は数量と送信識別子を保ち、数量変更や通常削除を止めます。「送信と受付の再確認をする」は同じ内容・同じ識別子で再送するため、既存APIの重複防止が働きます。
3. 注文履歴や担当者に確認し、再送不要と分かった場合だけ「確認済みなので外す」を使います。確認ダイアログが表示されます。これはカートから外す操作で、保存済み注文の取消ではありません。
4. 最初の入力不備など受付前に拒否された場合は訂正できます。一度結果不明になった商品は、後で別のエラーが出ても結果が確定するまで編集を止めます。

担当者・会計・管理画面へのアプリ内切替ではカートと送信処理を保持します。再読み込み・ページを閉じる操作には、カートがある間だけブラウザ標準の確認を出します。ただしブラウザやOSによる強制終了、ログアウト、セッション失効、実際の再読み込みを越えてカートを復元する機能はありません。ブラウザ保存領域へ新たに注文データを保存していません。結果不明のときはページを閉じず、再確認または担当者への確認を先に行ってください。
